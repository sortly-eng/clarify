# Clarify by Sortly — Support

For questions, bug reports, or feedback about this plugin, [open a GitHub issue](https://github.com/sortly-eng/clarify/issues/new).

Include the plugin version, host application, steps to reproduce the problem, and a minimal example of the expected and actual behavior. Remove private code, credentials, personal data, and customer information before posting: this repository and its issues are public.

For a privacy question, describe the question without including sensitive information. Maintainers can discuss the appropriate next step in the issue. Account access, billing, and conversation deletion for ChatGPT, Codex, Claude Code, or another host application are handled by that application's support team.

Clarify is an open-source project; support is provided on a best-effort basis, with no guaranteed response time.
